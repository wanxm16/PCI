# 医药招商与流向库存系统 · AI 增强 Demo

在客户**已有**的招商管理、流向查询和库存管理功能之上，利用现有数据增加 AI 分析，帮助管理者和业务人员更快发现问题、确定优先级并落实到待办。

> 本仓库是前端演示（Demo V0.2），使用虚构的模拟数据，固定演示日期为 2026-11-03。

## 为什么这样做

客户的基础功能已经具备，只是觉得用起来不够好。我们不重做这些功能，而是在现有页面旁边加上 AI，回答"数据说明了什么、接下来该做什么"：

- **用现有数据**：流向、库存、客户、招商机会、授权、推广、任务、销售目标，不需要额外录入。
- **放进现有页面**：诊断作为页签放在对应业务页面里，不用切换系统。
- **结论直接给出**：打开就能看到指标、重点对象和分析结论，想深入再追问。
- **能变成行动**：结果可以生成待办草稿或简报，确认后进入任务中心。

## AI 功能一览

| 场景 | AI 功能 | 在哪里 |
|---|---|---|
| 销售管理 | 经营变化归因 · 客户流失预警 · 目标达成与缺口 · 团队与个人业绩分析 | 经营工作台、AI 经营洞察 |
| 招商与渠道 | 招商漏斗诊断 · 授权与推广健康度 | 招商进度管理、合伙人授权 |
| 库存运营 | 临期库存去化建议 | 库存管理 |
| 查询与汇报 | 流向查询结果分析 · 经营洞察与异动提醒 · 经营简报与周会材料（可下载 Word / Markdown） · AI 经营助手（对话） | 流向查询页、AI 经营洞察、各页面侧栏 |

每项功能的详细说明、示例数字和"现有功能 vs 加上 AI"的对比，见 **[AI功能说明.md](./AI功能说明.md)**。

## 可信与可控

- 所有数字由统一的指标与规则层计算，和页面报表口径一致，并附查询编号和数据截止时间。
- 数据能证明的"观察"和需要人判断的"待核实"分开列出。
- AI 只能看到当前用户有权限的数据。
- AI 只生成草稿，不会自动审批、变更状态或对外发送。
- 目前为**规则解析模式**，没有接入大模型；接入后数字仍由指标层计算。

## 快速开始

需要 Node.js 18 或更高版本。

```bash
cd demo
npm install
npm run dev      # 打开 http://localhost:7321
```

其他命令：`npm test`（运行测试，锁定演示数字与规则）、`npm run build`（类型检查并构建）。

右上角可以切换演示角色（经营负责人 / 区域业务人员），点"重置"恢复初始数据。演示主线、页面说明、业务口径和目录结构见 **[demo/README.md](./demo/README.md)**。
